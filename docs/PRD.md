# PRD: NovaMind Landing Page

## 1. Executive Summary
Static landing page for NovaMind — an Autonomous Multi-Agent Platform
with Defense-in-Depth Security. Design: Dark Glassmorphism.

## 2. Target Audience
- Developers seeking autonomous agent frameworks
- Enterprise architects evaluating security-first tools
- AI/ML engineers interested in multi-agent swarms

## 3. Core Sections
1. Hero — headline, sub, 2 CTAs
2. Stats Bar — 4 metrics
3. Features Grid — 4 glass cards
4. Tech Stack — badges
5. Footer — links

## 4. Design System
- Theme: Dark only
- Palette: slate-950 bg, cyan-400 primary, amber-500 secondary
- Typography: Inter + JetBrains Mono
- Effects: backdrop-blur 12-16px, 300ms transitions

## 5. Technical Constraints
- Astro 4+ static output
- Tailwind CSS
- Deploy: GitHub Pages
- Responsive mobile-first
