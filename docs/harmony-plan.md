## 2. جواب السؤال المؤسِّس — أين التناغم حقيقي وأين لا

**حقيقي ومختبَر عند الجسور**: المنسق core يختار من وكلائه العشرين ثم ينفّذ
ويحاكم عبر موجّه LLM المركزي من novamind (`novamind.core.llm_router`) وشخصيات
مجلسه الستة وجينومه الموحّد (GenomeV2 مصدر الحقيقة الوحيد بعد ADR
`docs/GENOME_UNIFICATION.md`)، والجرد الموحد (106) يوحّد الأسماء الثمانية
المكررة بمفتاح `(framework, name)`، والتوجيه يقرأ درجة الأسطول الحية وقت
القرار (`src/fleet/reader.py` — ف4 مغلقة في v1.50.0).

**لا يبلغ مستوى "توزيع المهام باحتراف الشركات العالمية"** لسبع فجوات
مثبتة بالأرقام — تُفصَّل في §3 وتُغلق موجةً موجة.

## 6. ما لن نفعله (ملزم كقسم «ما سنفعله»)

1. **لا توحيد للذاكرة أو طبقة LLM في هذه الجولة** (ت6) — قرار معماري له
   باب منفصل؛ الجسور الثلاثة القائمة تُبقي المنصة عاملة ومختبَرة.
2. **لا قياس سلوكي شامل للـ79 في هذه الجولة** (ت7) — توسيعه يغير ميزانيات
   CI؛ يُعلن كموجة قادمة بمعاييرها.
3. **لا حذف للطرفية أو القنوات** — TUI وتيليجرام والصوت ليست «واجهات تطبيق
   ويب»، وحذفها يكسر 3,000+ سطر اختبار ووعود README بدون مكسب.
4. **لا لمس عقود API** — حذف الواجهات لا يحذف مساراً واحداً من المواصفة.
5. **لا مجلس يوقف عمل** — حتى في escalate: التصعيد استشاري، والرفض الصريح
   فقط يمنع النشر لا التنفيذ.
