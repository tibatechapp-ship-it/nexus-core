# A2A — التشغيل البيني بين الوكلاء (م4 — v1.56.0)

> **نسخة المواصفة المثبَّطة**: A2A **0.3.0** (لقطة 2025-11) — نقل
> **JSONRPC فقط**، غير المتدفق. الجزئية المنفذة: بطاقة الوكيل (Agent
> Card) + دورة اكتشاف/رسالة/رد عبر JSON-RPC 2.0. البثّ (streaming) و
> pushNotifications غير منفذين — و`capabilities` تعلن ذلك **بصدق**
> (`false`). رفع نسخة المواصفة يستوجب مراجعة معلنة وتحديث هذه الوثيقة
> واختبار conformance في PR نفسه (نفس منهجية MCP مع 2026-07-28).

## 1. البطاقة — من مصدر واحد للحقيقة

* **بطاقة المركز**: `GET /.well-known/agent.json` — مهاراتها
  (council / agents / memory)، و`url` نقطة الرسائل يُشتق من مضيف
  الطلب نفسه فتظل البطاقة صحيحة في أي نشر بلا إعدادات إضافية.
* **بطاقات الأسطول**: `GET /api/a2a/cards` — **106 بطاقة** تُولَّد
  تلقائيًا من الجرد الحي (`src.fleet.build_inventory`)، لا قائمة
  موازية ولا نسخ يمكن أن تتقادم. اسم البطاقة `nexus-<agent>` (وعند
  تكرار الاسم بين الأطر: `nexus-<agent>.<framework>`)، ومهارتها
  الوحيدة `agent:<name>` بوسوم `(category, framework, role)`.
* الحقول الإلزامية (عقد conformance يعتمدها): `name, description,
  url, version, protocolVersion, capabilities, defaultInputModes,
  defaultOutputModes, skills[]` — المفاتيح على الشبكة camelCase.
* `validate_card()` فحص صرامة في `src/a2a/card.py`؛ `version`
  البطاقات = `src.__version__` (مصدر واحد).

## 2. الرسائل — JSON-RPC 2.0

`POST /api/a2a/message`:

```json
{"jsonrpc":"2.0","id":1,"method":"message/send",
 "params":{"message":{"role":"user","kind":"message",
 "messageId":"m-1","parts":[{"type":"text","text":"…"}]}}}
```

الرد: `result` برسالة `role:"agent"` (نص) أو `error` قياسي:
`-32700` مغلّف غير صالح · `-32601` طريقة غير مدعومة · `-32602`
معاملات غير صالحة · `-32603` فشل معالج (fail-closed: لا تسريب
تفاصيل داخلية عبر الشبكة).

المعالج الافتراضي **محلي حتمي** (إيصال توجيه باسم المنصة ونسخة
المواصفة) — بلا LLM ولا شبكة؛ المهارات المدعومة بالـ LLM تُبلغ عبر
`/api/agent/run`. أي فشل معالج يُترجَم إلى `-32603` لا استثناء متسرب.

## 3. الصادر — الخصوصية بقائمة سماح صريحة

`A2AClient(root, allowlist=[...])` — قاعدة مطلقة: **لا اتصال صادر
إلا بضمّان المضيف صراحةً** (معامل أو `NEXUS_A2A_ALLOWLIST` مفصولة
بفواصل). الافتراضي رفض الكل (`PrivacyError`).

* الدورة بمواصفة حقيقية: اكتشاف `<root>/.well-known/agent.json` →
  الإرسال إلى **`url` البطاقة** (لا للجذر) — الاكتشاف يغذي هدف الإرسال.
* **لا SSRF عبر بطاقة ماكرة**: `card.url` يمرّ بقائمة السماح هو
  الآخر — بطاقة تُوجّه الإرسال لمضيف غير مسموح تُرفض قبل أي بايت.
* النقل قابل للحقن (`transport`) — الاختبارات صفر شبكة.
* التقييد المعلن بالمواصفة: مطابقة مضيف حرفية، بلا wildcards.
