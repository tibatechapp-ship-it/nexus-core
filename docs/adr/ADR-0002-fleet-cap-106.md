# ADR-0002: أسطول موحّد بسقف 106 وكلاء — لا زيادة

- **الحالة**: مقبول (2026-11 — docs/V2_ROADMAP.md §10 «غير أهداف»)
- **السياق**: إضافة وكلاء بالجملة تبدو إنتاجية لكنها تُنتج تكرارًا
  وأسماء متضاربة وصفًا متقادمًا (كنا نعلن «20 وكيلًا» بينما الجرد
  الحيّ يقول غير ذلك).
- **القرار**: مصدر واحد للحقيقة = `src.fleet.build_inventory()`؛
  الأسطول موحّد ومجرد ومقاس، **السقف 106** — أي وكيل جديد يمرّ
  بمراجعة تستوجب حذف/دمج آخر.
- **البدائل المرفوضة**: «كلما احتجنا أضفنا» — طريق تضخم CrewAI.
- **النتائج**: بطاقات A2A الـ106 تُولَّد من الجرد نفسه (م4)؛ تقارير
  الأسطول نضرة ببوابة CI؛ لا قوائم موازية يمكن أن تتقادم.
