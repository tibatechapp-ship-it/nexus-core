# ADR-0005: عقود مستقرة معلنة تُفشل CI عند التغيير غير المعلن

- **الحالة**: مقبول (2026-11 — م3/v1.55.0 · docs/CONTRACTS.md)
- **السياق**: ض7 — واجهاتنا العامة (llm_router، مخطط الأثر) كانت
  قابلة للتغيير بصمت؛ الاستهلاك الداخلي الواسع يجعل أي انزلاق
  توقيع كسرًا متسلسلًا لا يُكتشف إلا لاحقًا.
- **القرار**: واجهة **العقود المستقرة**: توقيعات مثبّتة حرفيًا
  (inspect.signature) وسلوك مثبّت (قاطع الدارة بجدوله الكامل) في
  `tests/test_llm_router_contract.py` — أي تغيير غير معلن يُفشل
  CI، والتعديل يستوجب تحديث `docs/CONTRACTS.md` في PR نفسه.
  نفس المنهج لنسخ المواصفات: MCP يثبّت 2026-07-28 وA2A يثبّت 0.3.0.
- **النتائج**: المفاضلة الصريحة: احتكاك مراجعة أعلى مقابل ثقة
  خارجية قابلة للإثبات — الرهان: العقد يُرفع بمراجعة معلنة لا
  بالتسلل.
- **البدائل المرفوضة**: deprecation warnings فقط (لا إجبار) —
  النظام الحي يستدعي الدوال مباشرة فلا بديل عن البوابة الصلبة.
