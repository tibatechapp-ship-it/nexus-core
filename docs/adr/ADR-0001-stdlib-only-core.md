# ADR-0001: صفر اعتماديات وقت التشغيل — بايثون قياسي خالص

- **الحالة**: مقبول (2025 — منشأ المشروع؛ مُوثَّق هنا في 2026-11)
- **السياق**: منصات الوكلاء تتراكم عليها تبعيات تتقادم وتتسرب أمنيًا
  (درس AutoGen: أعتمادية واحدة ميتة تقتل الإطار كله).
- **القرار**: النواة (src/ ما عدا طبقة novamind الاختيارية) تعمل على
  Python 3.11+ **stdlib فقط** — لا pip ولا venv ولا تجميع.
- **البدائل المرفوضة**: pydantic/langchain/requests — كلها تكسر
  «يعمل على الهاتف» وتضاعف سطح الهجوم.
- **النتائج**: تشغيل في أي بيئة معزولة؛ اختبار كل ميزة جديدة يشمل
  «هل بقيت stdlib؟»؛ الاستثناء الوحيد المعلن: طبقة الخادم novamind
  (fastapi…) اختيارية عبر extras `novamind`.
