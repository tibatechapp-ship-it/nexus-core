## 2. منهجية الخطة — لماذا هذه «محكمة»

1. **دليل قبل بند**: لا بند بلا رقم مقيس أو ملف يُفحص اليوم.
2. **معيار قبول آلي**: كل بند ينتهي باختبار أو بوابة أو مقياس في التقرير —
   إن لم يُقَس آلياً فهو ليس معيار قبول بل رجاء.
3. **بوابات لا مجاملات**: كل موجة تُغلق بإصدار مُوسوم، والتقارير المجددة
   تُطابق الواقع (104+ وكيلاً مُقاساً لا معلناً فقط).
4. **صدق بيئي**: القياسات الجديدة تعلن حدودها (ما هو حقيقي وما بطيء زائف
   معلن) — لا أعداد صارمة تتقلب بالبيئة.
5. **ضبط نطاق صريح**: قسم «ما لن نفعله» ملزم كما قسم «ما سنفعله».

## 5. الحوكمة والقياس — كيف نعرف أننا نتقدم

- **إيقاع المراجعة**: نهاية كل موجة = إصدار موسوم + تقارير مجددة + CI 10/10
  + تحديث هذه الوثيقة (حالة البنود: ⏳/🔨/✅).
- **KPIs أربعة لا أكثر**:
  1. تباين الدرجات (انحراف معياري > 0 بدل الإشباع) — ف1.
  2. `cross_framework_overlap == 0` — ف2.
  3. نسبة قرارات التوجيه المسجلة بدرجتها في الأثر = 100% — ف4.
  4. عمر التقارير عند كل إصدار = 0 إصدارات تخلف — ف5.
- **عقد الطبقات باقٍ**: S لا يهبط تحت A بلا بند إصلاح في أول PR (دستور
  `fleet-operations.md` §2 — لا تعديل عليه في هذه الخطة، بل إثباته بقياس أعمق).

## 7. ما لن نفعله — ضبط النطاق (ملزم)

1. **لا توحيد إطارات كامل** (دمج novamind في core أو العكس) — قرار معماري
   أكبر من خطة تحسين، وله باب منفصل.
2. **لا قياس شبكة حقيقي لـnovamind** — كل القياس أوفلاين/بطاطم زائفة معلنة.
3. **لا تغيير في أوزان بوابات الجودة** (ruff/mypy/تغطية 95%) — البوابات
   القائمة تعمل، والخطة تضيف قياساً لا تخفف حواجز.
4. **لا إصدار بلا تقارير مطابقة** — من الآن فصاعداً التقارير جزء من تعريف
   «الإصدار» لا زينة لاحقة.
