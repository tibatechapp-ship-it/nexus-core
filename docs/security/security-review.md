## نتائج الجولة 2026-11-26

1. **كاش الوكلاء (B324)**: أزيل MD5 واستُبدل بـ SHA-256 على تمثيل JSON كامل للزوج
   `[agent, prompt]`. لم يعد نص المطالبة يُختصر إلى 200 محرف، ولم يعد اسم الوكيل الخام جزءاً من مسار الملف.
2. **سلامة الكتابة**: الكتابة إلى ملف مؤقت خاص ثم الاستبدال الذري؛ فشل التخزين يبقى غير قاتل لمسار تنفيذ الوكيل، ولا يُنشئ مجلدات جديدة ضمن دالة الكتابة.
3. **القراءة**: رفض الروابط الرمزية باستخدام `O_NOFOLLOW` عند دعم النظام والتحقق من بنية سجل JSON.
4. **منع تسرب ملفات المراجعة**: PR #183 يعالج قراءة symlink خارج مساحة المراجعة، واجتازت بواباته الأربع على رأسه الموثق.
5. **حد FastAPI**: PR #166 يرفع حد التبعية إلى الإصدار المعالج؛ يجب أن يدخل الإصلاح إلى خط الإصدار قبل نشر صورة إنتاج.
6. **حدود الثقة**: نجاح الفحص الآلي لا يعادل تدقيقاً مستقلاً كاملاً، ولا يثبت سلامة إعدادات الأسرار خارج Git أو نشر الإنتاج.

## بنود متابعة مفتوحة

- توسيع SAST ليشمل كامل كود التطبيق النشط واستثناء المجلدات المؤرشفة/المهاجرة بوضوح.
- فرض سياسة حقول مسموح بها في سجل الأثر ومنع مفاتيح/قيم المحتوى الحساس.
- إعادة التحقق من سرّ الأتمتة وتاريخ التدوير عبر إعدادات GitHub، لا عبر نصوص المستودع.
- توسيع بوابة منع آثار التشغيل إلى المسارات التي يكتب إليها التطبيق فعلياً.

لا تعتبر البنود ذات الحالة الجزئية أو المفتوحة ضوابط مكتملة. لا يوجد في هذه الجولة نشر إنتاجي.
