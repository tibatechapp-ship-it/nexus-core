## نتائج التحديث 2026-11-26

1. **B324 في كاش الوكلاء**: أزيل MD5 واستُبدل بـ SHA-256 على هوية JSON كاملة
   `[agent, prompt]`. هذا يعالج أيضاً تصادم بادئة المطالبة بعد أول 200 محرف،
   ويمنع إدخال اسم الوكيل الخام في مسار الملف.
2. **حماية الكاش**: أضيفت كتابة ذرية، صلاحيات ملف 0600، فتح مع
   `O_NOFOLLOW` عند توفره، والتحقق من بنية الإدخال قبل إرجاع النتيجة.
3. **B602 التاريخي**: الإشارة القديمة إلى `src/agent_loop/tools.py` غير دقيقة.
   سجل إزالة أداة `run_shell` الخطرة محفوظ في `CHANGELOG.md`؛ أمثلة
   `shell=True` المتبقية موجودة في `docs/legacy` المؤرشفة، وليست مسار
   تنفيذ التطبيق النشط. لا تُعامل أنماط البحث أو الاختبارات التي تحتوي
   النص كتنفيذ فعلي.
4. هذه الوثيقة تسجل تغييرات الملفات والبوابات؛ لا تدعي تدقيقاً مستقلاً كاملاً
   ولا نشر إنتاجي. اعتماد النتائج مشروط بنجاح CI ومراجعة PR.
