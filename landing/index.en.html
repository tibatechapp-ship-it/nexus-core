Unified AI Agent System

Memory + Learning + Security + 20 Agents

One repo, two layers. Framework is pure Python stdlib-only (phone-safe). 1218 tests @ 99% coverage. Every feature kept.

Core Features

20 AI Agents

Core/planning/quality/ops + registry/sub-agent with depth limits and tool scoping.

4-Type Memory

Episodic, semantic, procedural, emotional — SQLite stores with recall/forget and retention.

Continual Learning

Experience → lessons, anti-forgetting, consolidation and a learning orchestrator.

Offline Security

8 regex agents + orchestrator, CLI with --fail-on (low/medium/high/critical).

Workflows

Supervisor, Pipeline (resumable checkpoints), Fanout, Delegation, Blackboard.

TUI + Tool Traces

ToolRuns, Lessons screens, streaming, checkpoints and security export.

Architecture

src/
  agents/       20 built-in agents
  core/         types, backend, streaming, context, resilience
  patterns/     Supervisor, Pipeline (resumable), Fanout, Delegation, Blackboard
  memory/       4 SQLite stores
  learning/     experience collector → lessons → anti-forgetting
  security/     offline scanner (8 agents) + CLI
  tools/        read-only ReAct loop
  tui/          Textual UI (tool traces, lessons)
  novamind/     opt-in extras (server/RAG/observability)

Quick Start

# Framework (stdlib-only)
python -c "from src.core.backend import EchoBackend; print('OK')"

# TUI (Echo backend offline)
python -c "from src.core.backend import EchoBackend; from src.tui.app import run_app; run_app(backend=EchoBackend())"

# Install extras
python -m pip install -e ".[dev]"           # tests/tooling
python -m pip install -e ".[voice,tui]"     # voice + TUI
python -m pip install -e ".[novamind]"      # opt-in server layer

Verify before shipping

ruff check .
mypy zyvo-telegram.py zyvo-voice.py src
python scripts/check_annotations.py
python -m pytest --cov  # 1218 tests @ 99%
