Why nexus-core?

🛡️ The MIZAN suite — six engines closing the Snyk/Semgrep gaps

An independent competitive comparison (November 2026) identified six gaps versus enterprise platforms — all closed in v1.59.0 with pure `ast`. Every engine declares its limits honestly. 156 regression tests, six CLIs with documented exit codes.

س1 Deterministic repair

Bump plans at the lowest declared fixed version, dry-run by default, weekly workflow opens a least-privilege PR.

Honest limit: never guesses versions the source did not declare as fixed.
python scripts/mizan/mizan_fix.py requirements.txt

س2 Reachability

Tri-state verdict per advisory: reachable / import-only / absent — repairs get ranked, not deleted.

Honest limit: direct imports only; transitive ones may stay invisible.
python scripts/mizan/mizan_reach.py . --manifest requirements.txt

س3 Cross-file taint

Source→sink across files with a chained trace: "a.py:2 input() → b.py:7 get() → c.py eval".

Honest limit: in-project scope; textual names; declared step budget.
python scripts/mizan/mizan_taint.py .

س4 Advisory mirror

Single-file sqlite3 mirror with a declared 24-hour freshness SLA — network failure is announced, never swallowed.

Honest limit: no proprietary database, no zero-days — public sources only.
python scripts/mizan/mizan_mirror.py --db .mizan/adv.db sync --osv

س5 GRC dashboard

Static HTML (RTL, zero JS) aggregating multiple repositories + ISO 27001 / SOC 2 / PCI DSS control maps.

Honest limit: "suggested control coverage" — no certification claims.
python scripts/mizan/mizan_grc.py --report r1.json --out dashboard.html

س6 Custom rules

JSON DSL over `ast` (node + dotted pattern + flat regex) + 7 reviewed built-in rules.

Honest limit: simple matching — not full Semgrep.
python scripts/mizan/mizan_rules.py check . --rules team-rules.json

🚧 Honest limits — stated in full

The project's identity: honesty before cleverness. These limits are declared in code and docs, not hidden:

  • Benchmarks measure the framework on the pure EchoBackend path — live-model measurement is not a published tool yet.
  • MIZAN س3 (taint) covers in-project scope only; س4 mirrors public sources — we own no proprietary vulnerability database and claim none.
  • The /dashboard panel and trace ledger cover the src/web layer and registry agents; unified_agent chat tracing is separate.
  • The novamind layer is an optional extra and stays outside framework gates — it has its own suite in CI.
  • GRC control maps are "suggested coverage" from a reviewed data file — no certifications.
