🛡️ منظومة MIZAN — ستة محركات تغلق فجوات Snyk/Semgrep

مقارنة تنافسية مستقلة (نوفمبر 2026) رصدت ست فجوات مقابل منصات المؤسسات — أُغلقت كلها في v1.59.0 بـ`ast` خالص، وكل محرك يعلن حدوده بصراحة. 156 اختبار انحدار، وست أدوات CLI بأكواد خروج موثقة.

س1 الإصلاح الحتمي

خطط bump بأدنى إصدار مُصلح معلن، تجفيف افتراضي، workflow أسبوعي يفتح PR بأقل صلاحية.

الحد الصادق: لا يخمّن إصدارات لم يعلن المصدر إصلاحاً لها.
python scripts/mizan/mizan_fix.py requirements.txt

س2 Reachability

حكم ثلاثي لكل إعلان: reachable / import-only / absent — والإصلاحات تُرتّب لا تُحذف.

الحد الصادق: استيراد مباشر فقط؛ الانتقالي قد يبقى غير مرئي.
python scripts/mizan/mizan_reach.py . --manifest requirements.txt

س3 تلويث عبر الملفات

مصدر→مصرف عبر الملفات بسلسلة مخيطة: «a.py:2 input() → b.py:7 get() → c.py eval».

الحد الصادق: داخل المشروع؛ أسماء نصية؛ ميزانية خطوات معلنة.
python scripts/mizan/mizan_taint.py .

س4 مرآة الإعلانات

sqlite3 من ملف واحد بـ SLA نضارة 24 ساعة معلن — فشل الشبكة يُعلن ولا يُفرّغ.

الحد الصادق: لا قاعدة ملكية ولا zero-days — مصادر عامة فقط.
python scripts/mizan/mizan_mirror.py --db .mizan/adv.db sync --osv

س5 لوحة GRC

HTML ساكن (RTL، صفر JS) يجمّع مستودعات عدة + خرائط ISO 27001 / SOC 2 / PCI DSS.

الحد الصادق: «تغطية ضوابط مقترحة» — لا ادعاء شهادات.
python scripts/mizan/mizan_grc.py --report r1.json --out dashboard.html

س6 قواعد مخصصة

DSL بصيغة JSON فوق `ast` (عقدة + نمط dotted + regex مسطح) + 7 قواعد مدمجة مُراجَعة.

الحد الصادق: النطاق مطابقة بسيطة — لا Semgrep كاملاً.
python scripts/mizan/mizan_rules.py check . --rules team-rules.json

🚧 الحدود الصادقة — لنتحدث بها كاملة

هوية المشروع: الصراحة قبل الذكاء. هذه الحدود معلنة في الكود والتوثيق، لا نخفيها:

  • القياسات المعيارية تقيس إطار العمل على مسار EchoBackend الخالص — قياس النماذج الحية ليس بعد أداة منشورة.
  • MIZAN س3 (التلويث) يغطي داخل المشروع فقط؛ وس4 مرآة مصادر عامة — لا نملك قاعدة ثغرات ملكية ولا نزعم ذلك.
  • لوحة /dashboard وسجل الأثر يغطيان طبقة src/web ووكلاء الـregistry؛ تتبع دردشة unified_agent مستقل.
  • طبقة novamind اختيارية (extras) ولا تدخل بوابات الإطار — لها جناحها في CI.
  • خرائط ضوابط GRC «تغطية مقترحة» من ملف بيانات مُراجَع — لا شهادات.
