# Web Standards Skill — معايير الويب الحديثة

## الغرض
كود واجهات ويب حديث يلتزم معايير المنصات: بنية نظيفة، وصولية حقيقية،
أداء معقول، وأمان للواجهة — بأولوية عربية RTL في كل قرار تصميمي.

## الخطوات
1. ابدأ بالبنية: HTML دلالي (header/nav/main/section) قبل أي تزيين
2. الوصولية أولوية لا تُسقَط: تباين نص ≥ 4.5:1، تركيز لوحة مفاتيح واضح،
   aria-label للعناصر غير النصية، ترتيب قراءة منطقي
3. RTL أولًا: كل تنسيق يُكتب منطقياً (start/end لا left/right)، ويُختبر
   بالمعكوس أيضاً؛ الحروف العربية لا تُقص أبداً عند حدود الحاوية
4. لا اعتماد على شبكة خارجية: الأصول محلية (خطوط، تظليل كود) — وإلا
   فالواجهة محجوبة بلا إنترنت
5. الأداء: صور lazy، لا خطوط ثقيلة، جافاسكربت مؤجَّل، لا حلقة تحديث
   تحرق المعالج
6. أمان الواجهة: لا innerHTML بنص مستخدم، لا أسرار في الكود الأمامي،
   CORS مقيد لا *

## القواعد
- كل عنصر تفاعلي له حالة تركيز مرئية — ما لا تراه أنت لا يراه مستخدم
  لوحة المفاتيح أيضاً
- manifest وservice worker بصحة حقيقية: مسارات الأيقونات موجودة،
  ووضع offline يعمل فعلاً لا شعاراً
- لا CDN خارجي في واجهة إنتاجية — استنسخ الأصل إلى web/vendor
- قيّس قبل أن تدّعي السرعة: أكبر عنصر ظاهر ≤ 2.5s على جهاز متوسط
- العربية ليست إضافة لاحقة: سطر عربي واحد يكسر الاتجاه إن أُهمل —
  اختبر به قبل التسليم
